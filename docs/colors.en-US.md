Ant Design interprets colors at system and product levels. System colors define
basic, neutral and data visualization palettes; product colors communicate brand
identity and functional states. This page adapts the React v6 color examples to
interactive Blazor components.

## Color Model

HSB makes hue, saturation and brightness adjustments predictable and helps teams
communicate about color.

## Base Color Palettes

The interactive page displays all 120 colors: ten swatches for each of Dust Red,
Volcano, Sunset Orange, Lime, Calendula Gold, Sunrise Yellow, Polar Green, Cyan,
Daybreak Blue, Geek Blue, Golden Purple and French Magenta. Hover to inspect
values and click or keyboard-activate a swatch to copy it.

The displayed order, names and descriptions are synchronized from React's
`ColorPalettes.tsx`; values are generated by the shared C# library rather than
hard-coded copies of the 120 colors.

## Neutral Color Palette

Like React's color document, the preview displays ten neutral swatches: `#fff`,
`#fafafa`, `#f5f5f5`, `#f0f0f0`, `#d9d9d9`, `#bfbfbf`, `#8c8c8c`, `#595959`,
`#434343`, `#262626`. The synchronized source catalog also retains the remaining
three definitions (`#1f1f1f`, `#141414`, `#000`); the preview count comes from React's
`Palette.tsx`. These are specification colors, not a generated gray palette.

## Data Visualization Color Palette

Combine basic and neutral colors with AntV's effective, clear, accurate and

## Palette Generation Tool

The interactive page uses real Blazor `ColorPicker` components. The initial main
color is `#1890ff`; the dark tool also allows changing its `#141414` background.
Both tools call `ColorPalette.Generate` and preserve unique swatches in order.
After a color change, saturation or brightness below 70% displays a recommendation.

## Programmatic Usage

```csharp
using AntDesign.Colors;

var blue = ColorPalette.Generate("#1677ff"); // all ten swatches
var primary = blue[5];
var secondary = blue[0];
var dark = ColorPalette.Generate("#1677ff", dark: true, backgroundColor: "#141414");
```

This is the same C# implementation used by theme tokens and two-tone Icons,
ported from Ant v6's `@ant-design/colors` dependency. No JavaScript color calculation
is involved; JavaScript is used only for browser clipboard access.

## Color Application In Enterprise Product Design

Use color with restraint to communicate information, guide actions and provide
feedback without reducing clarity or efficiency.
