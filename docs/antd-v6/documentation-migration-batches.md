# Documentation migration batches

The documentation migration is complete when the three hosting models render the
same documentation features with Ant Design v6 component styles, all Dumi-owned
layout rules are represented by Blazor markup and `CssInJs.CreateStyles` objects,
and the old compiled documentation stylesheet is no longer loaded. Verification
must include builds and browser checks for the home page, component page, theme
preview, Semantic DOM preview, responsive navigation, and theme modes.
