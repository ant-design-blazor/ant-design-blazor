ConfigProvider 用于为组件树提供统一的方向、主题和表单配置。

## 何时使用

当应用需要统一配置 Ant Design 组件的主题、文字方向或全局行为时使用。

## API

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| Direction | 文字方向 | string | -- |
| Theme | 全局主题 | GlobalTheme | -- |
| ThemeConfig | Design Token 与组件主题配置 | ThemeConfig | -- |
| Form | 表单全局配置 | FormConfig | -- |
