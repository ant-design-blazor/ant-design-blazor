## zh-CN

使用 Table 组件分别渲染穿梭框两侧。每侧的数据源独立传入，共享的单侧面板通过方向参数回传选择事件。

## en-US

Customize each transfer side with a Table. Each side receives its own data source and direction-aware selection callbacks; selected rows move between the source and target data sets.
