## zh-CN

左侧使用 Tree，右侧使用共享的穿梭框列表。树节点展平成带 key 的选项数据，方向参数决定当前选择和移动操作作用于哪一侧。

## en-US

Use a Tree for the source side and the shared transfer list for the target side. The tree is flattened into keyed transfer items, and direction determines which side's selected keys are moved.
