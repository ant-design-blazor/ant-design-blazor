Listy renders a grouped list of items.

## API

| Parameter | Description | Type | Default |
| --- | --- | --- | --- |
| DataSource | List data | IEnumerable&lt;TItem&gt; | - |
| GroupBy | Grouping function | Func&lt;TItem, string&gt; | - |
| Height | List height | int | 0 |
| ItemHeight | Item height | int | 32 |
