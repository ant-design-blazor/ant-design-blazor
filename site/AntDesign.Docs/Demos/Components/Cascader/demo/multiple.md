## zh-CN

使用 `Multiple` 开启多选；通过 `ShowCheckedStrategy` 控制标签显示父节点、子节点或全部已选节点。`DisableCheckbox` 可单独禁用某个节点的复选框。

## en-US

Set `Multiple` to enable checkbox selection. `ShowCheckedStrategy` controls whether tags display checked parents, checked leaves, or all checked nodes. `DisableCheckbox` disables an individual checkbox without disabling its option.
