## zh-CN

使用 `MaxCount` 限制头像组中直接展示的头像数量，悬停溢出头像可查看其余头像。调整数量可验证溢出行为。

## en-US

Use `MaxCount` to limit the number of avatars shown inline. Hover the overflow avatar to view the remaining avatars; change the count to exercise the overflow behavior.
