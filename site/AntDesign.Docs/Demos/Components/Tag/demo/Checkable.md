## zh-CN

可通过 `Tag.Checkable` 实现单个可选标签；`CheckableTagGroup` 提供单选和多选模式，并分别通过 `Value` / `Values` 绑定选择结果。


## en-US

`Tag.Checkable` works like a checkbox. `CheckableTagGroup` supports single and multiple selection, bound through `Value` and `Values` respectively.

    it is an absolute controlled component and has no uncontrolled mode.
