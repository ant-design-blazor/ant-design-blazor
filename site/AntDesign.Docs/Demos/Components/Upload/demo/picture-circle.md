## zh-CN

使用 `PictureCircle` 展示圆形图片列表，包含已完成、上传中和失败状态。上传按钮会继续使用组件的真实文件选择与上传交互。

## en-US

Use `PictureCircle` for a circular picture list with done, uploading, and error states. The upload button uses the component's real file selection and upload interaction.
