## zh-CN
通过 `Count` 自定义计数策略、最大计数和超出最大值时的格式化方式。示例按文本元素计数，因此 emoji 按一个字符计算。

## en-US
Use `Count` to customize the counting strategy, displayed maximum, and formatting when the value exceeds that maximum. The examples count text elements, so an emoji is counted as one character.
