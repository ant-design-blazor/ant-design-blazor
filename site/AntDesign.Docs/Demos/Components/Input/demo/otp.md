## zh-CN

使用 `InputOTP` 输入一次性验证码，支持格式化、粘贴分发、遮罩、分隔符、禁用状态和键盘切换。
`@bind-Value` 可接收部分输入，`OnChange` 仅在所有输入框填写完整且值改变时触发；`OnInput` 接收各格的值。

## en-US

Use `InputOTP` for a one-time code, with formatting, paste distribution, masking, separators, disabled state, and keyboard navigation.
`@bind-Value` receives partial input; `OnChange` fires only when every cell is filled and the completed value changes. `OnInput` receives the individual cells.
