## zh-CN

使用 `ActionsRender` 自定义预览工具栏，可保留默认操作并通过上下文调用缩放、旋转、翻转、重置和关闭操作。

## en-US

Use `ActionsRender` to customize the preview toolbar. Its context exposes the default actions and callbacks for zooming, rotating, flipping, resetting, and closing.
