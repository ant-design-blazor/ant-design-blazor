## zh-CN

通过 `ProgressRender` 自定义确定进度占位符。上下文提供经过四舍五入并限制在 0–100 的百分比，以及可选复用的默认进度条和百分比指示器。

## en-US

Use `ProgressRender` to customize a determinate progress placeholder. Its context provides the percentage rounded and clamped to 0–100, plus the default progress rail and indicator for optional reuse.
