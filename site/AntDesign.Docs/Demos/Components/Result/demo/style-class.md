## zh-CN

通过语义化 `ClassNames` 和 `Styles` 自定义 Result 的根节点、图标、标题、描述、内容和操作区域。不同状态可以使用不同的样式集合。

## en-US

Customize the Result root, icon, title, subtitle, body, and extra semantic nodes with `ClassNames` and `Styles`. Different statuses can use different style sets.
