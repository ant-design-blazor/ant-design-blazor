## zh-CN

添加 `Loading` 属性即可让按钮处于加载状态。使用 `LoadingIcon` 可以自定义加载图标；下面的按钮还演示了图标位于文字前后、替换原图标，以及点击后进入加载状态。

使用 `AutoLoading` 属性可为绑定 `OnClick` 回调的异步方法自动处理加载状态。

## en-US

A loading indicator can be added to a button by setting the `Loading` parameter. Set `LoadingIcon` to customize its icon. The examples also show loading states with icons before or after the text, replacing an existing icon, and starting on click.

Use the `AutoLoading` parameter to automatically add and deactivate load states for asynchronous methods that bind the `OnClick` callback.
