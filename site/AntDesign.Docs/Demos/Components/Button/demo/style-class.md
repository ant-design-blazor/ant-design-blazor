## zh-CN

通过 `ClassNames` 和 `Styles` 对象自定义 Button 的 `root`、`icon`、`content` 语义 DOM 样式。需要根据参数动态生成样式时，可使用 `ClassNamesFunc` 和 `StylesFunc`。

## en-US

Customize Button semantic DOM slots (`root`, `icon`, and `content`) using `ClassNames` and `Styles` objects. Use `ClassNamesFunc` and `StylesFunc` to derive them from the current component parameters.
