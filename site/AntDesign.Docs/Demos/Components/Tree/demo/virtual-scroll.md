## zh-CN

开启 `Virtualize` 后，Tree 会使用虚拟列表渲染可见节点。滚动容器需要设置高度，`ItemSize` 用于估算单行高度。

## en-US

Set `Virtualize` to render tree rows through a virtual list. Give the scroll container a height, and use `ItemSize` to set the estimated row height.
