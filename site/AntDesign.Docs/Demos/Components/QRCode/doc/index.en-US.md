QRCode renders text as a QR code.

## API

| Parameter | Description | Type | Default |
| --- | --- | --- | --- |
| Value | QR code content | string | - |
| Size | QR code size | int | 160 |
| Status | Current status | string | active |
| Bordered | Whether to show a border | bool | true |
