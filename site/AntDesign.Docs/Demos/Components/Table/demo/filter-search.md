## zh-CN

`filterSearch` 用于开启筛选项搜索，也可以传入自定义方法来匹配搜索内容。

## en-US

`filterSearch` enables searching filter items. You can also provide a custom function to match the search input against each filter record.
Search the available name and address filter options, apply one or more filters, and sort by age.
