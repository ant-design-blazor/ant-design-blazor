本例将展开图标列放在 Team 列之后，并固定前三列。React v6 使用 `expandedRowOffset`；Blazor 对应使用 `ExpandedRowOffset`，并通过 `ExpandIconColumnIndex` 控制展开图标列的位置。

## en-US

This example places the expand-icon column after Team and fixes the first three columns. React v6 uses `expandedRowOffset`; the Blazor equivalent is `ExpandedRowOffset`, while `ExpandIconColumnIndex` controls the expand-icon column position.
