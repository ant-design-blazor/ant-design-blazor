title:
  en-US: Responsive columns
  zh-CN: 响应式列
---

Hide columns at narrower viewport widths by setting the column `Responsive` breakpoints. By default, the `md` column is visible from 768px and the `lg` column from 992px. These thresholds follow the `screenMD` and `screenLG` theme tokens and can be customized with `ConfigProvider`.
