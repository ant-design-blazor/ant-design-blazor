## zh-CN

使用 `OptionRender` 自定义下拉选项的内容。模板接收选项元数据、源数据项和当前可见列表中的索引。

## en-US

Use `OptionRender` to customize dropdown options. Its context exposes the option metadata, source item, and zero-based index in the visible, sorted list, corresponding to React's second `optionRender` argument.
