## 自定义分词

`Tokenize` 回调可以根据输入内容自定义提交时机和拆分规则。此示例在输入以分号结尾时提交其中的标签。

## Custom tokenization

The `Tokenize` callback lets you define when and how search text becomes tags. This example commits values when the input ends in a semicolon.
