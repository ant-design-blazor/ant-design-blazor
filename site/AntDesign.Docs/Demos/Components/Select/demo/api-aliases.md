The Select exposes React-compatible names for popup height and custom icons.
`ListHeight` controls the option-list height; `Prefix`, `MenuItemSelectedIcon`,
and `RemoveIcon` customize the corresponding content. `FilterOption` can keep
all options visible while typing, and `FilterSort` orders the filtered results.
