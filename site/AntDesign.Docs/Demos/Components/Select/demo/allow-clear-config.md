## zh-CN

通过对象配置清除按钮的辅助名称、键盘导航顺序、自定义图标或禁用状态。布尔值 `AllowClear` 用法仍然可用。

## en-US

Configure the clear button's accessible label, tab order, custom icon, or disabled state with an options object. The boolean `AllowClear` form remains available.
