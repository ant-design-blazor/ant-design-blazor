## When To Use

Can be used to separate areas horizontally or vertically. When you need to freely drag and adjust the size of each area. When you need to specify the maximum and minimum width and height of an area.

Set `ShowCollapsibleIcon` on `SplitterPanel` to always show or hide collapse buttons, or show them only while hovering the divider.

The `customize` demo also shows custom dragger/collapse icons and Splitter component tokens.
