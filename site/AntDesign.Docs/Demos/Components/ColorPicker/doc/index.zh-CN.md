颜色选择器用于选择颜色，并支持受控的打开状态和值变化。

## 何时使用

当需要让用户选择颜色或预览主题色时使用。

## API

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| Value | 当前颜色值 | string | `#1677ff` |
| Open | 是否打开面板 | bool | false |
| ShowText | 是否显示颜色文本 | bool | false |
| Disabled | 是否禁用 | bool | false |
| AriaLabel | 颜色按钮的无障碍标签 | string | Choose color |
