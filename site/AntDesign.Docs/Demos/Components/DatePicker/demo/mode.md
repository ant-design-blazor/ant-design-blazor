## zh-CN

通过 `OnPanelChange` 观察当前面板，并将面板类型同步回选择器。Blazor 使用 `Picker` 类型管理面板；RangePicker 的两个面板共享同一类型。

## en-US

Use `OnPanelChange` to observe the active panel and synchronize it back through `Picker`. Blazor uses the picker type to manage panels; both RangePicker panels share the same type.
