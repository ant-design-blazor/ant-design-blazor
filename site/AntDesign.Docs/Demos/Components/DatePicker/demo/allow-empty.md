## zh-CN

日期范围值允许一端为空。选择开始日期后，可以保留结束日期为空，表示“至今”。与 React 的 `allowEmpty` 元组不同，Blazor 通过可空范围值表达这一状态。

## en-US

A range value can have an empty endpoint. Select a start date and leave the end date empty to represent an open-ended range. Blazor expresses this with nullable range values rather than React's `allowEmpty` tuple.
