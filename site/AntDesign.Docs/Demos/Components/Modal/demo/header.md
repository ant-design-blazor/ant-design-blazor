## zh-CN

设置 `Header` 属性可以自定义消息框的头部。默认头部组件在 [ModalHeader.razor](https://github.com/ant-design-blazor/ant-design-blazor/blob/master/components/modal/modalDialog/ModalHeader.razor)。

另外，如果设置 `Header` 为 null 可隐藏头部。

## en-US

Set the `Header` property to customize the header of the Modal. Default header component in [ModalHeader.razor](https://github.com/ant-design-blazor/ant-design-blazor/blob/master/components/modal/modalDialog/ModalHeader.razor).

Otherwise, if `Header` is set to null, the header can be hidden.
