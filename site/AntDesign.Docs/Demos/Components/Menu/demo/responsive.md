## zh-CN

横向 Menu 自带逐项收纳能力。调整宽度后，放不下的菜单项会进入省略号子菜单，宽度恢复后自动还原。此示例使用点击打开子菜单，支持动态条目、路由链接、禁用项和选中状态。Flex 布局中的菜单容器需要允许收缩（`min-width: 0`）。设置 `DisabledOverflow` 可禁用自动收纳。

## en-US

Horizontal Menu automatically moves items that do not fit into the ellipsis submenu and restores them when space becomes available. Change the width or toggle the extra item, then try selection, disabled items, nested submenus and routing. This example opens submenus on click. Allow flex containers to shrink with `min-width: 0`. Set `DisabledOverflow` to disable responsive overflow.
