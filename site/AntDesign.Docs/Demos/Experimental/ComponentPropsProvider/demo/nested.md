## zh-CN

Provider 可以嵌套。内层会继承外层集合，并只覆写自身显式设置的字段。本例内层按钮同时具有外层的 `Primary` 类型与内层的 `Disabled` 属性。

## en-US

Providers can be nested. An inner provider inherits the outer collection and overrides only the properties it explicitly sets. The inner buttons in this example are both `Primary` from the outer scope and `Disabled` from the inner scope.
