## zh-CN

同一个 `ComponentPropsProvider` 可以传入多个 Props 类型。此示例将两个 Button 设为主按钮，给顶部和底部 Pagination 都启用快速跳转，并仅为底部 Pagination（`Table<T>.BottomPaginationId`）启用页码大小切换。

## en-US

One `ComponentPropsProvider` can contain multiple props types. This example makes both buttons primary, enables quick jumping on both paginations, and enables the page-size changer only on the bottom pagination (`Table<T>.BottomPaginationId`).
