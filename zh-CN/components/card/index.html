API

Card卡片

通用卡片容器.

何时使用

  • 最基础的卡片容器，可承载文字、列表、图片、段落，常用于后台概览页面。

Examples

典型卡片

包含标题、内容、操作区域。 可通过设置size为default或者small，控制尺寸

无边框

在灰色背景上使用无边框的卡片。

更灵活的内容展示

可以利用 Card.Meta 支持更灵活的内容。

网格型内嵌卡片

一种常见的卡片内容区隔模式。

栅格卡片

在系统概览页面常常和栅格进行配合。

内部卡片

可以放在普通卡片内部，展示多层级结构的信息。

预加载的卡片

数据读入前会有文本块样式。

支持更多内容配置

一种支持封面、头像、标题和描述信息的卡片。

简洁卡片

只包含内容区域。

带页签的卡片

可承载更多内容。用 StandaloneInCard 属性可在 Card 中独立使用 Tabs，以避免与其他内容冲突。
