Anchor锚点

用于跳转到页面指定位置。

何时使用

需要展现当前页面上可供跳转的锚点链接，以及快速在锚点之间跳转。

Anchor API#

属性 描述 类型 默认值
Key 属性用于在密钥更改时刷新链接列表。 String --
ChildContent 属性组件的内容。 RenderFragment --
Affix 属性Anchor固定模式 Boolean true
Bounds 属性锚点区域的边界距离 Int32 5
GetContainer 属性滚动容器 Func<String> window
OffsetBottom 属性计算滚动位置时从底部偏移的像素 Int32? --
OffsetTop 属性计算滚动位置时从顶部偏移的像素 Int32? 0
ShowInkInFixed 属性Fixed模式下是否显示墨球 Boolean false
OnClick 属性设置处理程序来处理点击事件 EventCallback<Tuple<MouseEventArgs, AnchorLink>> --
GetCurrentAnchor 属性自定义锚高亮 Func<String> --
TargetOffset 属性锚点滚动偏移，默认为 AntDesign.Anchor.OffsetTop Int32? --
OnChange 属性当锚点改变时执行的回调，无论是通过点击还是滚动 EventCallback<String> --
Id 属性组件 HTML 的 ID String Uniquely Generated ID
Class 属性为 DOM 元素指定一个或多个类名。 String --
Style 属性指定 DOM 元素的内联样式。 String --
RefBack 属性一个 ForwardRef 实例。您可以使用 AntDesign.ForwardRef.Current 获取对内部 DOM 的引用。 ForwardRef --
